# Gelişmiş Fonksiyonel Keşifçi Veri Analizi (EDA)

Veri setini sistematik olarak analiz etme metodolojisi.

  - 📓 [`gelişmiş_fonksiyonel_keşifçi_veri_analizi.ipynb`](./gelişmiş_fonksiyonel_keşifçi_veri_analizi.ipynb): Aynı içerik, çalıştırılmış çıktılarıyla birlikte Jupyter Notebook formatında.
- **gelişmiş_fonksiyonel_keşifçi_veri_analizi_Tekrar_İçin_Sorular.pdf:** Modülün tamamını kapsayan çoktan seçmeli tekrar soruları ve cevap anahtarı.
